# Engladder — полный курс английского (офлайн)

Бесплатный интерактивный курс английского языка для русскоговорящих: уровни A1–B2 (сейчас готов A1, юниты 1–14, два повторения, итоговый тест).
Работает целиком в браузере, без сервера, аккаунтов и сбора данных. Прогресс хранится только в вашем браузере (localStorage, ключ `ec1`).

Автор: Ярослав Бадин. Сообщения об ошибках: encourseyan@yandex.ru.

## Запуск локально

Скачайте репозиторий и откройте `index.html` двойным щелчком. Интернет не нужен.
Если нужен локальный сервер: `python3 -m http.server 8000` и адрес `http://localhost:8000`.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | только разметка и подключение файлов |
| `css/styles.css` | оформление (цвета в CSS-переменных, тёмная тема) |
| `js/data/` | только данные: `core.js` (контейнеры `U` и `TB`), `units/<id>.js` (по файлу на юнит или повторение), `units-finish.js`, `levels.js` (карта уровней `PL`), `bank/<id>.js` (банк тестов `TB` по юнитам), `reference.js` (общие разделы справочника `ref0`), `glossary.js` (словарь `G`) |
| `js/app.js` | логика и интерфейс: прогресс, озвучка, вкладки, тест, справочник, словарь |
| `tools/build_single.py` | собирает всё в один автономный HTML (для проверок и для раздачи файлом) |
| `LICENSE` | полный текст CC BY-NC-SA 4.0 |
| `COURSE_HANDOFF_*.md`, `COURSE_CHANGELOG.md` | правила работы над курсом и журнал изменений |

Порядок подключения важен и задаётся тегами `<script>` в `index.html`: `js/data/core.js`, затем юниты, `units-finish.js`, `levels.js`, банк, `reference.js`, `glossary.js` и в самом конце `js/app.js`.

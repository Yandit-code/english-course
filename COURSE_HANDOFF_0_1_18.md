# Инструкция для Claude: как продолжить курс английского

## Для пользователя
Источник правды — репозиторий GitHub `Yandit-code/english-course` (ветка main). Новый чат начинайте в проекте «курс английского» и напишите: «Продолжи курс Engladder. Репозиторий Yandit-code/english-course. Прочитай из репозитория COURSE_HANDOFF_*.md (самый большой номер) и COURSE_CHANGELOG.md, затем скажи, где мы остановились». Если репозиторий недоступен, загрузите в чат index.html (или css/, js/), этот файл и журнал; если потеряно и это — загрузите любую скачанную копию курса и инструкции (старые версии хранятся у автора). Подробнее: раздел «Заметки для Claude и восстановление работы» в конце.

## Профиль ученика
Русскоговорящий, знает английский алфавит, звуки и небольшой список слов. Цель: B2 и выше, полноценный второй язык (чтение, письмо, речь, фильмы, книги, туризм, культура). Время: 1–2 ч в будни, 4–5 ч в выходные. Нужна работа офлайн. Версии Word/PDF делаем ПОСЛЕ того, как HTML будет готов полностью.

## Обязательные требования ученика
1. Весь английский текст переводится: слова, фразы, примеры, диалоги, тексты, подсказки. Для каждого нового слова — запись в словаре `G` (кликабельный перевод). Фразы разбираются по словам.
2. Теория подробная, на русском: правило, почему так, когда используется и когда НЕТ, типичные ошибки русскоговорящих, таблицы.
3. Упражнения сложные и разнообразные: выбор, исправление ошибок, перевод, подстановка формы. Не менее 12 на юнит.
4. Контрольная работа после каждого уровня с выводом: ≥85% идти дальше, 70–84% повторить слабое, <70% задержаться и пересдать.
5. Тексты для чтения, справочники (грамматика, клише, словарь) — всё внутри файла, без сторонних ресурсов.
6. Ничего не предполагать: любые вопросительные слова, местоимения, служебные слова объяснять с нуля.

## Архитектура (с версии 0.1.18 — несколько файлов, без внешних ресурсов)
Файлы: `index.html` (только разметка) · `css/styles.css` · `js/data.js` (ТОЛЬКО данные: `U`, `PL`, `TB`, `ref0`, `G`) · `js/app.js` (логика и интерфейс: прогресс, озвучка, вкладки, тест, справочник, словарь). Обычные скрипты (не модули), чтобы курс открывался по `file://`; порядок: `data.js`, затем `app.js`. `tools/build_single.py` собирает единый HTML (`dist/engladder_single.html`) для скриптов проверки и раздачи файлом. Ниже описано содержимое данных и логики (раньше всё лежало в одном файле).
- `U` — массив юнитов: `{t, ex(html теории), v:[[en,ru]], ph:[[en,ru]], dl(диалог), dt(перевод диалога), rd(текст), rt(перевод текста), q:[...], sp(задание на говорение)}`.
- `q`: выбор `{c:1,q,o:[],a:индекс,e}`; ввод `{t:1,q,a:["lowercase","варианты"],e}`. Ответы в нижнем регистре, апостроф ’.
- `PL` — карта уровней; `G` — словарь для клика по слову (`слово=перевод|…`); `TB` — банк заданий переходных тестов (поля `u`,`l`,`s`,`d`, формат как у `q`); `mk()` собирает тест по квотам (`PER`=3 на юнит), результат лучшего прохождения хранится в `P["a1-test"]`; `ref()` — справочник; `test()`/`fin()` — тест с вердиктом.
- Прогресс в localStorage, ключ `ec1`, ключи по id юнита (`a1-u03_5`). Кнопки навигации строятся из `U`; кнопка «Юниты N+ скоро» обновляется.
- Править файл точечно (python replace), после правок проверять `node --check` на выделенном скрипте. Внутри JS-строк не использовать прямые двойные кавычки (только « » и ’).

## Статус (актуально на версию 0.1.18)
Готово: юниты 1–14 (A1), «Повторение 1» (юниты 1–10, 30 упражнений) и «Повторение 2» (юниты 1–14, 31 упражнение), справочник (местоимения, to be, клише, времена, фразовые глаголы и др.), итоговый тест A1 (банк `TB` из 84 заданий, по 6 на юнит 1–14; тест из 42 вопросов, по 3 на юнит, каждый раз случайный), словарь `G` (~760 слов). Тексты для чтения (`rd`/`rt`) есть во всех юнитах 1–14.
Версии: номер версии живёт в этом файле (`COURSE_HANDOFF_0_1_N.md`), в `COURSE_CHANGELOG.md` и в комментариях-заметках внутри `index.html`/`js/*.js`; сам курс в репозитории лежит как `index.html` + `css/` + `js/` без номера в имени. Номер растёт с каждой контрольной точкой; в новом чате брать самый большой handoff. Бета `0.2.0-beta` присваивается только когда все файлы полностью проверены и автор дал слово.

## Справочник (правила автора)
1. Справочник содержит ВСЮ теорию из юнитов, включая новую.
2. На каждый раздел справочника — уникальный блок теории: разделы связаны между собой ссылками («см. юнит N»), но не копируют друг друга. Одну и ту же тему описываем один раз, в одном разделе; в остальных местах только короткая отсылка.
Реализация: `ref()` = `refAuto("A1", ref0())`. `ref0()` — общие разделы, не дублирующие юниты: «Навигатор: где какая тема» (таблица тема → юнит), «Порядок слов: сквозная схема», «Клише для общения», «Основные конструкции с предлогами», «Фразовые глаголы». `refAuto(L, base)` добавляет раздел `<h3>` на каждый обычный юнит уровня L с полным `ex` (внутренние `<h3>` → `<h4>`), так что теория юнитов попадает в справочник сама (сейчас 19 разделов). Удалены как дублирующие юниты прежние разделы «Местоимения», «Глагол to be», «Времена глагола», «have / has, прилагательные…» (их содержание в юнитах 1, 3, 4, 9, 11, 12).
Проверка перед каждой выдачей версии: собрать `ref()` и посчитать пересечения 7-словных фрагментов между разделами; допустимы только единичные короткие шаблонные фразы. При добавлении юнита: (а) добавить строку в «Навигатор», (б) если тема уже описана в другом юните, ставить отсылку вместо повтора, (в) ручные разделы (фразовые глаголы, предлоги, клише) пополнять только новым материалом.

## Журнал изменений и нумерация версий (правила автора)
1. Все изменения ведутся в одном файле `COURSE_CHANGELOG.md`: на каждую версию запись «что изменилось». Каждая новая версия курса добавляет запись сверху; в новом чате загружать три файла: курс, инструкцию и журнал.
2. Нумерация: сейчас `0.1.N`. Когда бета сайта будет готова, файлы курса получают номер `0.2.0-beta`, дальше последнее число растёт с каждым изменением (`0.2.1-beta`, `0.2.2-beta`…; суффикс `-beta` сохраняется, пока автор не объявит релиз). В именах файлов: `english-course_0_2_0-beta.html`, `COURSE_HANDOFF_0_2_0-beta.md`.

## Банк заданий: где он и как проверять
Банк `TB` лежит внутри файла курса, в скрипте, массив `var TB=[…]` перед `ref0()`. Тест собирается из него автоматически (`mk()`, по 3 вопроса на юнит). Проверка: на странице теста внизу блок «Банк заданий (для автора)» показывает счёт по юнитам и результат автопроверки (индексы, пояснения, метки, повторы, совпадения с упражнениями юнитов); список с ответами виден при адресе с `#author`. Это удобство, а не защита: файл курса открыт, и любой может прочитать банк в исходном коде. Настоящий закрытый раздел (доступ по ролям, ответы на сервере) возможен только с сервером и аккаунтами; для беты не нужен. Если захочется защитить тесты от подсматривания, варианты: вынести банк на сервер или регулярно обновлять банк (большой банк делает заучивание бессмысленным). Редактор банка для автора (оффлайн-страница, не публикуется) можно сделать отдельно после беты.

## Правило контрольных точек
После каждой контрольной точки (2–3 юнита, повторение, расширение теста и т. п.) Claude обязательно обновляет этот файл: «Статус», «Очередь доработок», «Журнал» — и выдаёт новую пару файлов с увеличенным номером версии. Так курс можно продолжить, даже если чат удалён.

## Видение продукта (слова автора, долгосрочно)
Бесплатные курсы с добровольными донатами (как у Blender). Блоки по уровням (A1–B2), в блоке юниты-занятия. Занятие = видео с теорией → текстовый повтор теории → практика → при возможности примеры из фильмов и книг. Выбор британского или американского английского. Смена внешней темы. Алгоритм расписания под каждого человека. Красивый интерактивный интерфейс. Достижения; маскот-тамагочи с настраиваемым видом, который изредка появляется сбоку и подбадривает. Переход на следующий уровень только после переходного теста; тесты собираются случайно из банка заданий. Карта знаний: что изучено, что нужно доработать.
Решения Claude, согласованные с автором: сначала содержание (A1 целиком), затем бета на бесплатном хостинге, потом функции по полезности для ученика: банк тестов и допуск → карта знаний → расписание и повторения (Leitner/SM-2) → темы → UK/US → достижения → маскот (выключаемый и редкий). Видео ведётся отдельно и параллельно; урок обязан работать без видео (видео = необязательное поле `vid`).

## Архитектурные принципы (обязательно соблюдать с версии 0.1.4)
1. Содержание отдельно от интерфейса: данные (`U`, `G`, `TQ`/банк) не смешивать с кодом показа; позже данные уровней выносятся в отдельные файлы.
2. У каждого юнита стабильный `id` (`a1-u03`, повторения `a1-r1`), прогресс хранится по id, а не по номеру.
3. Каждому вопросу метки: юнит `u`, навык `s` (gr, vo, rd, li, wr), уровень `l`, сложность `d` (1–3). Это нужно для случайных тестов, карты знаний и расписания.
4. Переходные тесты берутся из отдельного банка `TB` (не из упражнений юнитов), в банке в 3–5 раз больше заданий, чем в одном тесте; тест собирается по квотам тем, пересдача даёт новую выборку.
5. Варианты UK/US: различающиеся слова, написание и фразы хранить парой `{uk:…, us:…}`; озвучка выбирает голос en-GB или en-US.
6. Все цвета через CSS-переменные (основа для смены тем и тёмной темы).
7. Прогресс: один объект в localStorage с номером версии формата и экспорт/импорт кодом или файлом.
8. Видео `vid` и маскот необязательны: курс полностью работает без них и офлайн.
9. Авторские права: только свои тексты и диалоги и книги из общественного достояния; никаких кадров, реплик и длинных цитат из фильмов. Примеры из фильмов даём в виде пояснений без вставки материала.
10. Структура занятия сохраняется: видео (опц.) → теория → слова → диалог → чтение → практика → говорение.

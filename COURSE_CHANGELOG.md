# Журнал изменений курса английского

Формат: версия — что изменилось. Новые версии добавляются сверху. Файлы курса: `english-course_<версия>.html`, инструкция `COURSE_HANDOFF_<версия>.md`.

## 0.1.18
- Структура репозитория: монолит `index.html` разделён на `index.html` (разметка), `css/styles.css`, `js/data.js` (только данные: `U`, `PL`, `TB`, `ref0`, `G`) и `js/app.js` (логика и интерфейс). Обычные скрипты, не модули: курс открывается двойным щелчком и работает офлайн. Порядок подключения: `data.js`, затем `app.js`.
- Содержание курса не менялось. Проверка эквивалентности: старая и новая версии запущены в Node с заглушкой DOM, результаты совпали (112 записей `U`, банк 84, словарь 766 слов, справочник, вёрстка плана, юнита, повторения, справочника и словаря; тест из 42 вопросов по 14 юнитам).
- Название проекта: Engladder (заголовок страницы, «О проекте», README). Проверка названия по реестрам (ФИПС, WIPO, EUIPO, домен) остаётся за автором.
- Добавлены `README.md`, `LICENSE` (полный текст CC BY-NC-SA 4.0 с официального сайта Creative Commons), `.gitignore`, `tools/build_single.py` (сборка единого HTML для проверок и раздачи файлом).
- Добавлены заметки для Claude в `index.html`, `js/app.js`, `js/data.js` и раздел «Заметки для Claude и восстановление работы» в handoff.
- Проверки: `course-qa-gate` на собранном файле: 0 ошибок, 2 предупреждения (в банке меньше 10 заданий на юнит; 1 короткая шаблонная фраза в справочнике); `ru-legal-content-guard`: только безобидные срабатывания (имя голоса `google` в коде выбора озвучки, слова smoke и drugstore в бытовом контексте, ложное совпадение в слове «двойное», почта автора).
- Не сделано: проверка на устройствах и в браузерах, вычитка носителем, возрастной знак 0+, PWA для офлайна на сайте, налоговая консультация. Версия остаётся 0.1.x, `0.2.0-beta` присваивается только после полной проверки по решению автора.
